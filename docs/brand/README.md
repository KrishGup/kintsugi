# Kintsugi brand kit

Open `index.html` for the sheet (the mark, lockups, colour, type, do/don't). Everything here is generated by
`scripts/brand_assets.py` — change the drawing there, run it, commit the outputs.

| File | What |
|------|------|
| `kintsugi-mark.svg` | the mark on its blue square (primary) · `-navy`, `-white-bg`, `-mono`, `-mono-white`, `-bare`, `-navy-bare` colourways · `-heavy` = the icon build for ≤ 24 px · `-maskable` = square, inset for Android masks |
| `kintsugi-wordmark.svg` (+ `-white`) | KINTSUGI in Barlow Semi Condensed 700 as outlines (no font needed) |
| `kintsugi-lockup-h.svg` (+ `-dark`) | horizontal lockup — the default |
| `kintsugi-lockup-tag.svg` (+ `-dark`) | horizontal with the tagline |
| `kintsugi-lockup-stacked.svg` (+ `-dark`) | stacked, for square placements |
| `kintsugi-og.svg` | the 1200×630 social / Open Graph image |
| `png/` | PNG exports: mark 64–1024, icon 16/32/48, lockups @2x, `favicon.ico`, `kintsugi-og.png` |
| `fonts/` | Barlow Semi Condensed 600/700, IBM Plex Sans 400/500/600, IBM Plex Mono 400/500 (latin, woff2 + woff) with their OFL licences |
| `kintsugi-brand.css` | `@font-face` for the above plus the colour tokens — drop into any HTML document |

Colour: navy `#05142E` (ink), blue `#155DD3` (the one action colour, the mark's square), mid `#6C9EF0`, pale `#BED4F9`,
paper `#F3F7FE`; seam gold `#F2C14E` exists only inside the mark (`#D9A62B` on white).

The app serves its own copies from `web/public/` (favicon.svg/.ico, apple-touch-icon, icon-192/512 + maskable,
manifest.webmanifest, og.png), all written by the same script.
